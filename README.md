# Bibu Website

Statische Website für eine selbständige Bilanzbuchhalterin. Kein Backend und keine externen Frameworks erforderlich.

## Dateien

- `index.html` – Startseite
- `styles.css` – responsives Layout und Design
- `script.js` – mobile Navigation und dezente Scroll-Effekte
- `impressum.html` – Impressums-Vorlage
- `datenschutz.html` – Datenschutz-Vorlage
- `favicon.svg` – Platzhalter-Favicon
- `CNAME` – bestehende GitHub-Pages-Domain `bibu.muehler.at`

## Vor Veröffentlichung ersetzen

- `Vorname Nachname`
- `VN`
- `[Region]`
- `office@beispiel.at`
- `XX+ Jahre`
- alle Texte in eckigen Klammern

Impressum und Datenschutzerklärung sind Vorlagen und müssen auf die tatsächlichen Unternehmens-, Berufs- und Hostingdaten abgestimmt werden.
